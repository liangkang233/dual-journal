# 见闻 / 待办 / 纪念 展示美化 + 体验版

- 日期：2026-09-15
- 状态：用户确认方案 1，进入实现
- 发布目标：微信小程序**体验版**（方便朋友扫码，不走正式审核）

## 已确认范围

1. **见闻**：朋友圈式排版（作者圆标/昵称、「我/TA」、相对时间、正文、1–9 图九宫格）；**不做**点赞/评论。
2. **待办**：清晰列表行（勾选、标题、优先级色条、时间/地点摘要、倒计时）；未完成优先。
3. **纪念**：默认**月历**视图；可切换**列表**，列表展示**之后**的纪念日（按临近排序）；日历上有纪念的日期打点/角标。
4. 实现策略：只改现有页 WXML/WXSS/JS 展示层，不改数据模型；沿用暖色猫主题与现有背景。

## 非目标

- 点赞、评论、转发到朋友圈能力
- 正式提审上架（本轮只体验版）
- 重做 Tab 图标 / 配对逻辑

## 页面要点

### 见闻 `pages/feed/index`

- 卡片：顶行头像圆标（作者 openid 映射「我」或「TA」，可用名字首字）+ 相对时间
- 正文：最多约 4 行，超出省略；图：1 张大图 / 2–4 宫格 / 最多 9
- 点击进详情；空态保持现有插画

### 待办 `pages/todos/index`

- 列表行：左侧勾选，中间标题+元信息，右侧优先级标签（高/中/低色）
- 已完成降低对比度划线；整行可进编辑，勾选只切状态

### 纪念 `pages/anniversaries/index`

- 顶栏切换：日历 | 列表（默认日历，选择可 `storage` 记住可选）
- 月历：上下月切换；有纪念的日期标记；点日期可看当日条目或进编辑
- 列表：仅展示**今天及之后**（含每年循环的下一次），按下次日期升序

## 体验版发布

1. 开发者工具上传版本（如 0.2.0）
2. 公众平台 → 版本管理 → 选为体验版
3. 添加体验成员后扫码 / 分享体验二维码

## 成功标准

- 三页有数据时视觉明显优于旧卡片堆叠
- 纪念可日历↔列表切换且列表为后续纪念
- 可生成体验版供非开发者朋友打开查看
